# 撰写 Assignment 某一部分

## 华文指令

请只协助撰写或修订我指定的 Assignment 部分。

**我会提供：** Brief、Rubric、Lecture Notes、目标小节和字数、证据矩阵/来源原文、现有草稿及合作分工（如适用）。

**请先读取：** 与目标小节直接相关的要求、课程概念、证据和现有草稿。

**请完成：** 保留已完成部分；按指定字数组织段落，每段提出清晰论点、解释课程概念和证据如何支持论点，并回应题目/Rubric；用清晰正式的本科生英文。

**禁止：** 不重写无关或已完成章节；不编造证据或引用；不夸大来源；不把事实、推断和建议混为一谈；不因润色改变原意。

**完成后报告：** 修改范围、主要论证、实际使用证据、字数（如已计算）、尚未验证内容和下一步建议。

## English Prompt

Help draft or revise only the assignment section I specify.

**I will provide:** the Brief, Rubric, Lecture Notes, target section and word count, evidence matrix/source text, current draft, and group-work boundaries if relevant.

**Read first:** requirements, course concepts, evidence, and draft directly relevant to the target section.

**Do:** preserve completed sections; organize paragraphs within the requested word count; state a clear claim in each paragraph; explain how concepts and evidence support it; answer the task and rubric; and use clear formal undergraduate English.

**Do not:** rewrite unrelated or completed sections; invent evidence or citations; overstate sources; conflate facts, inferences, and recommendations; or change meaning while editing.

**Report:** the edited scope, main reasoning, evidence actually used, word count if calculated, unverified content, and next-step suggestions.
