# 开始新 Assignment

## 华文指令

请协助我开始一份新 Assignment。现在先分析要求，不要直接写完整作业。

**我会提供：** 本次 Assignment Brief、Rubric/Marking Scheme、相关 Lecture Notes、老师补充要求、提交规范及课程 AI 政策。

**请先读取：** 我本次明确提供的文件和与本任务直接相关的工作流程笔记。

**请完成：** 摘出题目动词、子任务、交付物、章节、字数、Rubric 评分重点、来源限制、引用格式、截止日期和待确认事项；制作 Rubric—课程概念—论点—证据—章节对照表。不适用的讲义内容标明“不适用”。

**禁止：** 不猜测缺失要求；不复用旧作业文字、引用、数据或评分规则；不扫描其他文件夹；不安装工具；不生成整篇作业。

**完成后报告：** 任务拆解、缺少/冲突的资料、建议的下一小步及需要我确认的内容。

## English Prompt

Help me start a new assignment. Analyze the requirements first; do not write the complete assignment yet.

**I will provide:** the current Assignment Brief, Rubric/Marking Scheme, relevant Lecture Notes, instructor instructions, submission rules, and the course AI policy.

**Read first:** only the files I explicitly provide and workflow notes directly relevant to this task.

**Do:** extract the task verbs, subtasks, deliverables, sections, word count, rubric criteria, source restrictions, citation style, deadline, and open questions. Build a rubric-to-course-concept-to-claim-to-evidence-to-section table. Mark irrelevant lecture content “not applicable.”

**Do not:** guess missing requirements; reuse old assignment wording, references, data, or rubric rules; scan other folders; install tools; or draft the whole assignment.

**Report:** the task breakdown, missing or conflicting materials, the next small step, and anything I need to confirm.
