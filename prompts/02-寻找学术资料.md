# 寻找学术资料

## 华文指令

请根据我提供的 Assignment 要求，为指定论点寻找少量相关学术和一手来源。

**我会提供：** Brief、Rubric、课程资料、要支持的论点、允许的数据库/来源类型和检索范围。

**请先读取：** 当前作业要求、相关课程概念及来源限制。

**请完成：** 说明实际使用的检索式和平台；优先用本地材料、官方出版方/机构页面及无需付费的公开资源；提供可复查链接；分别记录来源是否找到/存在性、适用书目字段、实际阅读范围及具体主张支持。将主张支持标为直接支持/部分支持/间接支持/不支持/待确认，并说明原文位置、研究对象/年份、适用范围和限制。对年报及统计数字核对原始科目、期间、单位、币种、Company/Group 口径和作业数值，并说明第二次独立复核是否完成。

**禁止：** 不编造来源、DOI、作者、年份、页码或研究结果；不把主题相关、DOI/元数据匹配或摘要说成全文支持；不把一般理论当作公司特定决策的直接证据；不混用会计科目或 Company/Group 数值；不发送完整作业、私人课程材料或密钥。免费 API 遇到 429、限额、登录墙或故障时停止该查询并标记，不转向付费服务、不购买或要求我粘贴 API Key。

**完成后报告：** 每个来源的存在性、书目信息、阅读范围、主张支持四项状态；量化事实的复核表；实际检索日期/平台；差异、局限及待确认事项。详细状态以 [完整工作流程 reference](../skills/assignment-research-skills/references/完整工作流程.md) 为准。

## English Prompt

Find a small number of relevant academic and primary sources for the specific claims in the assignment materials I provide.

**I will provide:** the Brief, Rubric, course materials, claims to support, allowed databases/source types, and search scope.

**Read first:** the current assignment requirements, relevant course concepts, and source restrictions.

**Do:** report the queries and platforms actually used; prefer local materials, official publisher/institution pages, and free public resources; provide checkable links; separately record source discovery/existence, applicable bibliographic fields, actual reading scope, and support for each specific claim. Classify support as directly supported/partly supported/indirectly supported/not supported/to be confirmed and state source location, study subject/year, applicability, and limits. For annual-report/statistical figures, check the original line item, period, unit, currency, Company/Group scope, assignment value, and whether an independent second check was completed.

**Do not:** invent sources, DOIs, authors, years, page numbers, or findings; treat topical relevance, DOI/metadata matches, or abstracts as full-text support; treat general theory as direct evidence for a company-specific decision; mix accounting line items or Company/Group figures; or send full assignments, private course materials, or keys externally. Stop a free API query at HTTP 429, a limit, login wall, or failure; do not switch to paid services, purchase a key, or ask me to paste an API key.

**Report:** separate source existence, bibliographic accuracy, reading scope, and claim support; quantitative fact-check records; actual query dates/platforms; discrepancies, limitations, and unresolved questions. Follow the [full workflow reference](../skills/assignment-research-skills/references/完整工作流程.md) for status definitions.
