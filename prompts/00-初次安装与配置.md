# 初次安装与配置

## 华文指令

我准备把这个 Assignment Research Skills 模板复制到自己的 Obsidian Vault。

**我会提供：** Vault 的准确本地路径；如有同名文件，提供我希望整合的方式。

**请先读取：** 模板中的 README、使用指南、完整工作流程和我指定的 Vault 目标位置中可能冲突的同名 Markdown 文件。

**请完成：** 检查目标路径存在、列出准备复制的文件、识别内部链接、列出名称冲突，并提出保留现有内容的整合计划。

**禁止：** 不扫描整个电脑或 Vault；不删除、覆盖、移动现有文件；不安装插件、Skill 或软件；未获我确认前不执行复制或合并。

**完成后报告：** 检查过的准确路径、将新增的文件、冲突文件、链接检查结果、未解决问题，以及需要我确认的操作。

## English Prompt

I plan to copy this Assignment Research Skills template into my Obsidian Vault.

**I will provide:** the exact local Vault path and, if filenames conflict, how I want them integrated.

**Read first:** this template's README, usage guide, full workflow, and any same-named Markdown files in the specific Vault destination that I identify.

**Do:** confirm the target path exists, list files proposed for copying, identify internal links and filename conflicts, and propose a merge plan that preserves existing content.

**Do not:** scan my whole computer or Vault; delete, overwrite, or move existing files; install plugins, Skills, or software; or copy/merge anything before I confirm.

**Report:** the exact paths checked, files proposed for addition, conflicts, link-check results, unresolved issues, and any action requiring my confirmation.
