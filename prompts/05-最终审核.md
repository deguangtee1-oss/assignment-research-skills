# 最终审核

## 华文指令

请只根据我提供的作业要求和材料进行最终审核，不虚构分数。

**我会提供：** 最终草稿、Assignment Brief、Rubric、Lecture Notes、老师要求、来源与数据记录。

**请先读取：** 上述本次作业文件及适用工作流程。

**请完成：** 逐项对照 Rubric，标为达成/部分达成/缺失；检查任务覆盖、证据与论点匹配、引用与参考文献对应、数据出处、字数、结构、格式、英文、图表/附录及提交规则。为每个问题标注文章位置和修改建议。

**禁止：** 不编造评分、来源或已完成核查；不改写整篇文章，除非我明确要求；不把未确认项目标成通过。

**完成后报告：** 已检查范围、Rubric 状态、优先修改项、未验证事项及提交前人工清单。

## English Prompt

Review my final assignment only against the materials I provide. Do not invent a grade.

**I will provide:** the final draft, Assignment Brief, Rubric, Lecture Notes, instructor requirements, and source/data records.

**Read first:** these current assignment files and the applicable workflow.

**Do:** mark each rubric criterion met/partially met/missing; check task coverage, evidence-to-claim fit, citation/reference correspondence, data sources, word count, structure, format, English, charts/appendices, and submission rules. Give each issue a document location and a suggested correction.

**Do not:** invent grades, sources, or completed checks; rewrite the whole paper unless I ask; or mark unresolved items as passed.

**Report:** the reviewed scope, rubric statuses, highest-priority revisions, unverified items, and a manual pre-submission checklist.
