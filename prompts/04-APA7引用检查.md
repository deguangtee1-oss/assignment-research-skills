# APA 7 引用检查

这是可独立复制的简短指令，不含完整 APA 字段手册。完整类型字段与核查步骤集中维护于 [`APA 7 引用核查 reference`](../skills/assignment-research-skills/references/APA7引用核查.md)。若你只复制本提示词且无法打开该链接，仍按下面的边界执行；不确定的类型规则或字段标为待确认，不凭记忆补足。

## 华文指令

请检查我当前作业的文内引用和 References。先检查当前 Coursework、Rubric 和教师指示；本次作业明确要求优先。若没有作业级格式说明，核对 TAR UMT Library 当前官方指南及适用的课程/学科例外。TAR UMT Library 指南将 APA 7 列为主要风格，同时说明部分课程可能采用其他风格。只有确认 APA 7 适用时才按 APA 7 细则审核；适用规则不明时标「待确认」，不要仅因一般 APA 7 细节不同就判违规。基本引用对应和来源证据检查仍可继续。

**我会提供：** 当前草稿、References、教师要求，以及需要时学校当前官方引用指南和允许在线查询的范围。

**请先读取：** 本次教师指示和我提供的适用指南。若可访问本项目 APA reference，按来源类型使用其详细清单；不得假设已经加载 Skill。

**请完成：**

1. 文内引用到 References、References 到文内引用，双向逐项核对；列出遗漏、孤立条目、重复和作者/日期不一致。
2. 按实际来源类型检查适用书目字段，指出每字段是已核实、缺失、待确认或不适用，并给出核查依据。
3. 分开报告 DOI/网址状态、书目信息准确性、实际阅读范围和来源对具体正文主张的支持（直接/部分/间接/不支持/待确认）；摘要只能支持摘要明确陈述的有限内容。
4. 标明未能访问的资料和需要人工完成的检查。

**安全边界：** 不猜或补造作者、日期、标题、出版者、DOI 或网址；不静默修复字段；不把 DOI/网址可访问、书目匹配或只读摘要说成全文支持；不把未执行的核查报告为通过。免费公开查询遇到限额、429、登录墙或故障时停止，记录失败/待确认，不切换付费服务、不购买或索取 API Key；仅发送必要的书目标识，不向外部服务发送完整作业或私人材料。

**完成后报告：** 适用格式及依据、双向匹配结果、逐项字段问题、来源/链接状态、阅读范围、主张支持状态、待确认事项和下一步。

## English Prompt

This is a short, independently copyable prompt, not the full APA field manual. Detailed type-specific checks are maintained in the [APA 7 reference](../skills/assignment-research-skills/references/APA7引用核查.md). If you copied only this prompt and cannot access that link, keep the boundaries below and mark uncertain type rules or fields to be confirmed; do not fill gaps from memory.

Check in-text citations and References in my current assignment. First check the current Coursework, Rubric, and instructor instructions; explicit assignment rules take precedence. If assignment-level rules are absent, consult the current official TAR UMT Library guide and applicable programme/course exceptions. The guide identifies APA 7 as the main style while recognizing that some programmes may use another style. Apply APA 7 details only when it is confirmed to apply; if the applicable style is unconfirmed, mark it to be confirmed and do not declare a violation based only on general APA 7 details. Basic citation matching and source-evidence checks can still proceed.

**I will provide:** the current draft, References, instructor instructions, and, when needed, my institution's current official guide and the scope allowed for online queries.

**Read first:** the instructor's instructions and the applicable guide I provide. If available, use this project's APA reference for detailed source-type checks; do not assume the Skill is loaded.

**Do:**

1. Check both directions: every in-text citation against References and every reference against the text. List missing, uncited, duplicate, and author/date-mismatch items.
2. Check applicable fields for the actual source type; report each field as verified, missing, to be confirmed, or not applicable, with its verification basis.
3. Report DOI/URL status, bibliographic accuracy, actual reading scope, and support for the specific claim separately (direct/partial/indirect/not supported/to be confirmed); an abstract supports only limited content it explicitly states.
4. Identify inaccessible materials and checks I must complete manually.

**Safety:** Do not guess or invent authors, dates, titles, publishers, DOIs, or URLs; do not silently repair fields; do not treat an accessible DOI/URL, matching metadata, or abstract-only review as full-text support; do not report unchecked work as passed. Stop free queries at limits, HTTP 429, login walls, or failures; record the limit/failure or uncertainty, never switch to a paid service, buy or request an API key, and send only necessary bibliographic identifiers—not full assignments or private materials—to external services.

**Report:** the applicable style and basis, both matching directions, field-level issues, source/link status, reading scope, claim-support status, unresolved items, and next steps.
