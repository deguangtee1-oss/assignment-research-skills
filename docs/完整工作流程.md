# 完整 Assignment 工作流程：用户概览

本页是给使用者的流程入口和简要导航，不重复维护完整规则。**阶段细则、Rubric/证据追踪字段和状态定义只在 [Skill 完整工作流程 reference](../skills/assignment-research-skills/references/完整工作流程.md) 维护**；可填写表格见[作业规划与证据记录模板](../skills/assignment-research-skills/assets/作业规划与证据记录模板.md)。

## 建议阶段

1. 收集当前 Brief、Rubric、相关 Lecture Notes、教师要求、提交规范和 AI 政策；列出缺失或冲突。
2. 逐项理解 Rubric，并把评分要求映射到课程概念、要证明的论点、证据及目标章节。
3. 按具体主张检索少量来源，分别记录来源存在性、书目信息、阅读范围和论点支持。
4. 写作前整理原文证据位置、适用范围及限制；只起草用户指定部分。
5. 按本次教师/学校规则核查引用；仅当作业要求 APA 7 时使用 APA 7。
6. 按每条 Rubric 独立进行最终审核，列出缺口、未执行检查及人工后续事项。

## 如何选择追踪表

- 简单作业：每项评分标准用一行追踪论点、来源、原文位置、正文位置、状态及下一步。
- 复杂作业：只有在来源多、来源复用或需要协作时，再使用独立来源台账并以 ID 关联。

具体字段含义、允许状态及最终审核规则以[详细流程 reference](../skills/assignment-research-skills/references/完整工作流程.md)为准。不要把来源存在、书目信息准确、实际阅读范围、论点支持和 Rubric 完成度合并为一个状态。

## English overview

This page is a user-facing overview, not a second copy of the detailed rules. The sole detailed workflow source is the [Skill workflow reference](../skills/assignment-research-skills/references/完整工作流程.md); the fillable fields are in the [planning and evidence template](../skills/assignment-research-skills/assets/作业规划与证据记录模板.md).

Use the current Brief, Rubric, relevant Lecture Notes, instructor requirements, submission rules, and AI policy. Map every criterion to a concept/claim, evidence, and target section; search only for specific claims; record source existence, bibliographic accuracy, reading scope, and claim support separately; draft only the requested portion; and review each Rubric criterion individually. Use a compact row per criterion for simple assignments. Add a separate source ledger only when the source relationships or collaboration require it. Follow the current Coursework and instructor instructions first. If assignment-level citation rules are unavailable, check TAR UMT Library's current official guide and any programme/course exception. If the applicable style remains unconfirmed, mark it to be confirmed; do not declare a violation solely from general APA 7 details.
