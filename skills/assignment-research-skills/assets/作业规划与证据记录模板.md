### Compact source checks (at least one row per Rubric criterion; link by Rubric ID)
Finding a source does not mean its bibliography is verified; topical relevance does not mean it supports the specific claim. Use one row per source. Repeat the Rubric ID when a criterion uses multiple sources. Use the full ledger below only when source relationships are complex.

| Rubric ID | Source and target claim | Source found/existence | Bibliographic accuracy | Actual reading scope | Supports this specific claim? | Exact source location, support scope, and limits | Gap/next action |
|---|---|---|---|---|---|---|---|
|  |  | Record found (not yet verified)/existence verified/not found in this search (does not prove nonexistence)/query failed/records conflict/to be confirmed | Verified/partly verified/missing/to be confirmed/not applicable | Full text/abstract/metadata/specified portion/unread | Directly supported/partly supported/indirectly supported/not supported/to be confirmed |  |  |

Record each material figure separately. Without the original table, an independent second check, or resolution of conflicting sources, retain “to be confirmed/discrepancy”; do not settle a figure from an abstract or metadata.

| Claim/measure | Original source and year | Page/table/section | Original line-item name | Reporting period/year | Currency and unit | Company/Group/other applicable scope | Original value | Value in assignment | Match and difference | Independent second-check method/result | Status | Limitation/next action |
